# 차량 조립 시뮬레이터 (Car Assembly Simulator)

## 개요

콘솔 기반의 대화형 차량 조립 시뮬레이터입니다.  
사용자가 단계별로 차량 타입, 엔진, 제동장치, 조향장치를 선택하여 차량을 조립하고, 조합의 유효성을 검증합니다.

---

## 실행 방법

```bash
javac Assemble.java
java Assemble
```

---

## 조립 단계 (Step Flow)

```
[1단계] 차량 타입 선택
    → [2단계] 엔진 선택
        → [3단계] 제동장치 선택
            → [4단계] 조향장치 선택
                → [5단계] RUN / Test
```

각 단계에서 `0`을 입력하면 이전 단계로 돌아갑니다.  
`exit`를 입력하면 프로그램을 종료합니다.

---

## 선택 옵션

### 1단계 - 차량 타입

| 번호 | 타입  |
|------|-------|
| 1    | Sedan |
| 2    | SUV   |
| 3    | Truck |

### 2단계 - 엔진

| 번호 | 엔진        |
|------|-------------|
| 1    | GM          |
| 2    | TOYOTA      |
| 3    | WIA         |
| 4    | 고장난 엔진 |

### 3단계 - 제동장치 (Brake System)

| 번호 | 제조사      |
|------|-------------|
| 1    | MANDO       |
| 2    | CONTINENTAL |
| 3    | BOSCH       |

### 4단계 - 조향장치 (Steering System)

| 번호 | 제조사 |
|------|--------|
| 1    | BOSCH  |
| 2    | MOBIS  |

## 부품 조합 제약 조건

아래 조합은 **유효하지 않으며** RUN 시 동작하지 않고, Test 시 FAIL 처리됩니다.

| 차량 타입 | 호환 불가 부품            | 사유                              |
|-----------|--------------------------|-----------------------------------|
| Sedan     | 제동장치: CONTINENTAL    | Sedan에 Continental 제동장치 사용 불가 |
| SUV       | 엔진: TOYOTA             | SUV에 TOYOTA 엔진 사용 불가        |
| Truck     | 엔진: WIA                | Truck에 WIA 엔진 사용 불가         |
| Truck     | 제동장치: MANDO          | Truck에 MANDO 제동장치 사용 불가   |
| (공통)    | 제동장치: BOSCH + 조향장치: MOBIS | BOSCH 제동장치는 BOSCH 조향장치와만 조합 가능 |

---

## 5단계 동작

### RUN
- 유효하지 않은 조합이면 `"자동차가 동작되지 않습니다"` 출력
- 고장난 엔진(4번) 선택 시 `"엔진이 고장나있습니다."` 출력
- 유효한 조합이면 선택된 부품 정보와 함께 `"자동차가 동작됩니다."` 출력

### Test
- 부품 조합 유효성을 검사하여 `PASS` 또는 `FAIL` 결과 출력
- FAIL 시 원인 메시지 함께 출력
